# portfolio-v2

Personal portfolio built in November 2022 as a 1-day project for a job fair. The
goal was simple: get basic info about me live and deployed within a tight
timeframe.

Built with Next.js and TypeScript, deployed on Vercel.

In February 2026 the codebase was updated to add a link to this site to my
latest portfolio website. No features of the original site were changed. The
original code is preserved under the `master` branch and the
[initial release tag](https://github.com/shchilkin/portfolio-v2/releases/tag/initial_release).

## Run locally

```bash
npm install
npm run dev
```
